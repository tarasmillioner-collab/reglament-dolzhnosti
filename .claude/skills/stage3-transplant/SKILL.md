# Stage 3 — TRANSPLANT
1. Из DNA.json возьми бит-лист с таймкодами. На каждый бит донора — бит клона с той же ролью и той же долей хронометража (±5%).
2. Каждый claim в бите → `F-NN` из FACTS.md. Нет факта — бит переписывается без claim.
3. SCRIPT_uk.md: объём слов = слов донора ±10% (по слов/сек из ДНК). Речь аватара (лексика из Avatar VOC), не копирайт. Числа — словами.
4. cards.json: карточка = 2–5 слов, `hot` слово = объект в кадре, `beat`, `role`, `shot` (что в кадре), `world` (hero|cutaway), `product_visible` (true только в мире героя).
5. `python3 gates/stage3.py` → судья judge-marketer → чинить только fail-items. Максимум 3 круга.

## Gotchas
- Оффер/цена/название в cutaway = T8 FAIL: продукт живёт только в мире героини.
- Враг (густой крем/воски) больше 12 кадров = T7 FAIL — cutaway-сюжеты варьировать (телефон, шарф, зеркало, фото).
- Секунда начала продажи должна совпасть с ДНК ±5% — не сдвигать оффер раньше «потому что так продаёт лучше».
- Ukrainian words are longer: считай слова, не символы; 142 wpm англ ≈ 120–130 wpm укр при той же длительности → всё равно целим ±10% по словам.
- Не оставлять донорские образы («новая жена», «магазин»): роль та же, образ свой (из Avatar: фото в профиль, шарф, Zoom).
