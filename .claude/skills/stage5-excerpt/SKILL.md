# Stage 5 — AUDIO → EXCERPT
5a. VO одним куском (tools/eleven_client.py или Higgsfield text2speech_v2/elevenlabs, женский голос). Gate: длительность = донор ±5%, слов/сек как в ДНК ±10%, max gap ≤1.2 с, −16 LUFS (`tools/audio_measure.py --vo`).
5b. `tools/whisper_words.py vo.wav` (в sandbox если локально нет весов) → words.json → `tools/timeline.py` раскладывает cards.json по таймлайну.
5c. Клипы: seedance_2_0_mini 480p 9:16, duration = ceil(длины карточки/группы карточек), start_image = стилл карточки. Сборка: `tools/assemble.py --timeline --vo --ass` (караоке: активное слово жёлтым, без плашки, чуть ниже центра, без ударений). → deliver/excerpt_rc1.mp4.
6. `python3 gates/stage5.py` → judge-sidebyside. Зелёный → DIGEST «EXCERPT READY», продолжать.

## Gotchas
- TTS по фразам запрещён (R7): интонация закрывается на каждой фразе. Один вызов на весь текст; если провайдер режет по лимиту символов — резать по актам, не по фразам, и склеивать с кроссфейдом 30 мс.
- eleven_v3 читает быстрее/медленнее донора — atempo 0.9–1.15 допустим, дальше меняется тембр; лучше править текст.
- Whisper теряет короткие слова («і», «не») — карточки раскладывать по найденным словам, пропущенные интерполировать по символам.
- Караоке: акцентные знаки (ударения) ломают OCR-гейт и выглядят как опечатки — без ударений.
- Seedance 5 с при карточке 2 с = лишние 3 с движения; резать клип по таймлайну, не растягивать карточку.
- Сборка: одинаковый fps/размер всех клипов ДО concat (scale=480:854, fps=30), иначе рассинхрон.
