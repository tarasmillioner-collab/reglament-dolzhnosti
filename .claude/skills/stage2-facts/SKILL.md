# Stage 2 — FACTS + ROLES
1. Прочитай gopure_docs/* и сайт целиком (без truncation). Если папки нет — источники из DECISIONS D-02 (Google Drive) и репо gopure-pages.
2. FACTS.md: одна строка = один факт = `F-NN | факт | источник (файл/URL + якорь)`. Ингредиенты, механизм, цена, старая цена, скидка (проверь: скидка ≠ старая цена, %), гарантия, доставка, срок результата, объём, фото, допустимые claims, запрещённые claims. Из Avatar: пол, возраст, боли, её слова.
3. Фото продукта → work/stage2/product_photos/ (≥3), проверь `python3 tools/ffprobe_wrap.py` на картинках (размер).
4. `python3 gates/stage2.py`.

## Gotchas
- Источники противоречат друг другу по ценам/гарантии — фиксируй все версии в FACTS с датами и решай в DECISIONS, не усредняй.
- «Клинические» claims с сайта могут быть запрещены самими исследованиями — заводи раздел «Запрещённые/рискованные claims».
- Скидка % считается от старой цены, не от суммы набора; проверь арифметику в FACTS (T5).
- Фото продукта с сайта часто CSS-background, не <img> — ищи в Drive/ассетах.
