# R_transplant — бинарная рубрика этапа 3 (judge-marketer, как покупательница из Avatar)
| id | Проверка |
|---|---|
| T1 | Хук первые 3 сек показывает боль аватара, не продукт |
| T2 | Есть proof-сцена (до/после без сплита, механизм, соцдоказательство из FACTS) |
| T3 | Есть сцена трансформации (жизнь ПОСЛЕ, не только результат на коже) |
| T4 | Цена показана против альтернативы (салон/процедуры/дорогие кремы) |
| T5 | Старая цена, новая цена, скидка — совпадают с FACTS (арифметика сходится) |
| T6 | Urgency и callback на хук присутствуют |
| T7 | Объект-враг ≤ 12 кадров, cutaway-сюжеты и камера варьируются |
| T8 | Оффер/цена/название — только в мире героя, никогда в cutaway |
| T9 | Каждый claim имеет источник в FACTS (F-NN) |
| T10 | Структура актов и секунда начала продажи совпадают с ДНК ±5% |
| T11 | Ни одного слова/образа донорского бренда |
| T12 | Текст звучит как речь аватара (лексика из Avatar), не как копирайт |
