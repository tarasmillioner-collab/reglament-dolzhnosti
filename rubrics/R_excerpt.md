# R_excerpt — отрезок клона рядом с 0–40 с донора (judge-sidebyside)
| id | Проверка |
|---|---|
| E1 | Ритм кадров как у донора ±15% (средняя длина кадра по битам первого акта) |
| E2 | Субтитры синхронны (OCR vs word-timestamps, дрейф ≤ 100 мс) |
| E3 | Героиня = паспорт во всех кадрах |
| E4 | Продукт = фото с сайта |
| E5 | Хук читается без звука (титры + картинка передают боль за 3 с) |
| E6 | Нет глитчей |
| E7 | Звук сплошной, с интонацией (нет TTS-по-фразам, gap ≤1.2 с) |
| E8 | «Слово = объект в кадре» на каждой карточке |
