# R_identity — стилл vs паспорт (judge-identity)
| id | Проверка |
|---|---|
| I1 | Тот же персонаж: возраст, черты лица, волосы, одежда как в паспорте/hero-ref |
| I2 | Тот же продукт: форма банки, цвет, крышка, надписи как на фото с сайта; нет выдуманных надписей |
| I3 | Тот же мир: палитра, свет, интерьер как в world.md |
| I4 | Нет текста/букв/цифр в кадре (кроме этикетки продукта из паспорта) |
| I5 | Нет глитчей рук/лица (пальцы, зубы, глаза, сросшиеся конечности) |
| I6 | Кадр соответствует карточке: «слово = объект в кадре» |
| I7 | Никаких случайных людей — только персонажи из extras.md |
