# R_decode — бинарная рубрика этапа 1 (judge-decode пере-измеряет; расхождение >10% = FAIL)
| id | Проверка |
|---|---|
| D1 | Длительность и WxH/fps совпадают с ffprobe донора (±1%) |
| D2 | Число сцен и средняя/медианная длина кадра совпадают с scene-cut пере-измерением (±10%) |
| D3 | Сцены покрывают 100% таймлайна без дыр и наложений |
| D4 | Слов в транскрипте и слов/сек совпадают с whisper (±10%) |
| D5 | Спето/сказано определено верно (pitch/ритм), BPM ±10%, громкость LUFS ±1 |
| D6 | Титры: стиль (плашка/цвет/позиция), число титров ±10%, караоке или нет |
| D7 | Каждый бит имеет таймкод, роль из списка, что в кадре, убеждение |
| D8 | Секунда начала продажи зафиксирована и совпадает с первым упоминанием бренда/оффера в транскрипте (±5%) |
| D9 | Объект-«враг»/«механизм» назван и число кадров с ним посчитано |
| D10 | Аудио-маршрут выбран по правилу (спето→Suno-first, сказано→VO+бед) |
