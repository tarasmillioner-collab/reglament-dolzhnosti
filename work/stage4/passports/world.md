# Паспорт мира (палитра, свет, стиль — по грамматике донора, не по его образам)
- Формат: вертикаль 9:16, 480×854 рендер (R1), фотореализм, кинематографичный, лёгкая плёночная зернистость.
- Кривая цвета как у донора (DNA colour.sat_thirds 38→57→69): I акт — приглушённый, холодноватый (офис, ванная, ночная кухня), насыщенность низкая; ч/б-провал на ране (B04 shot 18, 5.5 с); II акт — нейтральный дневной (кафе, тёплый бежевый); III акт — тёплый, насыщенный (вечерний офис с гирляндами, золотое окно).
- Свет: естественный оконный, мягкие тени; ночь — одна тёплая лампа; кафе — дневной рассеянный; корпоратив — тёплые гирлянды + практические источники.
- Локации (все «nice», как у донора): 1) офисная уборная с большим зеркалом; 2) ванная героини (светлая плитка, полка с флаконами без надписей); 3) кухня героини ночью (деревянный стол, лампа); 4) кафе (деревянный стол у окна); 5) офис вечером (гирлянды, люди с бокалами); 6) спальня/зеркало дома.
- Cutaway-мир (механизм/метафоры): чёрный или бумажно-белый фон, макро; бумага и маркер (анатомия), тонкая ткань + капля густого крема (вантаж), сухая губка + капля воды (купуасу), плод купуасу, женщины на солнечной улице.
- Камера: 35–50 мм, штатив/лёгкий handheld; крупность по DNA-ритму: I акт — быстрые средние/крупные; рана — медленный push; ментор — один статичный план.
- Бренд-цвета (F-04) только на end card: лаванда #D9CFF5 фон, индиго #4B3FD4 текст/кнопка, красный #E03A3A только для перечёркнутой старой цены.
- Запрещено: текст/буквы/цифры в кадре (кроме end card), логотипы, до/после-сплиты, случайные люди, стоковая «улыбка в камеру».
