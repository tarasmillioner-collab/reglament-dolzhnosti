# Регламент для должности

Скилл для Claude Code. Собирает должностную инструкцию с системой мотивации для сотрудника — в виде HTML-страницы с калькулятором дохода.

Работает так: сначала подробно расспрашивает владельца о роли, потом проверяет придуманную систему мотивации на типовые дыры, и только потом собирает документ.

## Зачем это нужно

Обычная проблема: владелец держит роль в голове целиком, но записывает кусками. В итоге получается либо список обязанностей без экономики, либо схема оплаты, которая через три месяца начинает работать против бизнеса.

Скилл ловит четыре вещи, которые почти всегда ломаются:

1. **Конфликт мотивации между направлениями.** Если один человек ведёт несколько направлений с разной измеримостью, быстрое и заметное вытеснит медленное и шумное. Это не про дисциплину — он посчитает доход на час и перераспределит время.
2. **Арифметика нормативов.** Месячный план × 12 должен сходиться с годовой целью, а сценарии дохода — быть достижимыми при заявленных нормативах.
3. **Статистика малых чисел.** Норматив вида «≥4 успешных из 15» промахивается по чистой случайности даже у сильного исполнителя. Лечится скользящим кварталом.
4. **Перегруз.** Часы по всем направлениям против ёмкости месяца. Роль, которая не помещается в месяц, уйдёт в имитацию — и первым отвалится самое трудозатратное и наименее оплачиваемое направление.

## Установка

```bash
git clone https://github.com/tarasmillioner-collab/reglament-dolzhnosti.git ~/.claude/skills/reglament-dolzhnosti
```

Перезапусти Claude Code — скилл появится в списке.

## Как пользоваться

Вызывается командой `/reglament-dolzhnosti` или просто фразой вроде «сделай регламент для должности», «как платить этому человеку», «оформи договорённость с сотрудником».

Дальше — интервью из семи блоков. Отвечать можно сумбурно, в том числе голосом: скилл вытаскивает смысл сам и не переспрашивает дважды. Если чего-то нет — помечает как открытый вопрос и идёт дальше, а не останавливает работу.

На выходе — HTML-страница: зона ответственности, нормативы по направлениям, что считается результатом, логика оплаты списком, калькулятор дохода с ползунками и обязательства компании.

Документ рассчитан на серию: один на каждого человека в команде, все в одном формате. Дизайн-система зафиксирована в шаблоне, поэтому второй и третий регламент собираются заметно быстрее первого.

## Что внутри

```
SKILL.md                      порядок работы: интервью → проверка → сборка → публикация
references/interview.md       расширенные вопросы, включая специфику по типам ролей
references/pitfalls.md        четыре проверки с формулами + типовые дыры в денежной части
references/design-system.md   палитра, шрифты, компоненты, правила калькулятора
assets/template.html          готовый скелет со стилями и рабочим калькулятором
```

Все числа в шаблоне синтетические — это пример структуры, а не чья-то реальная схема оплаты.

Claude Code. Внешних зависимостей нет — шаблон это один HTML-файл, шрифты подтягиваются с Google Fonts.
